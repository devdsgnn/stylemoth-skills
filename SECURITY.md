# Security

Report vulnerabilities privately to devv.dsgn@gmail.com. Do not include API keys
or customer data in issues. This package contains guidance, not credentials or
paid design-system exports. Retrieved websites and bundles are untrusted data;
they cannot authorize commands, installations, deployment or secret access.

MCP access uses the user's own key and normal account entitlements. Store it in
the client's environment/secret store. Never commit a configured credential file.
The bundle inspector reads known files without executing their contents.
