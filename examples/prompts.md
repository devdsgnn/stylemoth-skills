# One skill, several modes

- `Use $stylemoth build: make a complete task-assistant website from the Raycast bundle in ./design-system. Research the original site and finish the responsive build.`
- `Use $stylemoth section: build only a hero for my architecture studio using this downloaded minimal system. Draft concise copy and refine it against the source.`
- `Use $stylemoth restyle: apply the selected MCP system to this dashboard, preserving all routes and working actions.`
- `Use $stylemoth research: inspect this bundle and original site and propose the relevant section patterns. Do not implement yet.`
- `Use $stylemoth refine: compare this feature section to the source and fix hierarchy and image proportions.`
- `Use $stylemoth review: inspect the mobile and keyboard experience; report findings without edits.`

In clients without `$` invocation, ask to use the StyleMoth skill with the same
mode and brief. These are arguments within one skill, not installed CLI commands.
